# NATULEADAN(R) NEURAL DB(TM)

GPU-accelerated database engine. Written in Go with CUDA C kernels for GPU compute.

## Status

Early development. Currently a hello-world skeleton.

## Build

```bash
go build -o neural-db .
./neural-db
```

## Docker

```bash
docker build -t neural-db .
docker run --rm neural-db
```
